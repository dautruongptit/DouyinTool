# Douyin Tool (Nimo Kids Tool)

Lấy video hoạt hình từ kênh Douyin (kênh đã được đồng ý) → ghép video dài có watermark → phụ đề → đăng YouTube.

| Thư mục | Nội dung |
|---|---|
| `nimokids_core/` | Lõi nghiệp vụ dùng chung (không có giao diện) |
| `desktop/` | Bản máy tính Windows: bấm đúp `Mo Nimo Kids Tool.bat` (xem `desktop/DOC_TRUOC.txt`) |
| `web/` + `docker-compose.yml` | Bản web chạy bằng Docker: `cp .env.example .env && docker compose up -d --build` |
| `docs/` | `HUONG_DAN.md` (hướng dẫn đầy đủ), kiến trúc, lịch sử phiên bản |

Phiên bản hiện tại: xem `nimokids_core/__init__.py`.
